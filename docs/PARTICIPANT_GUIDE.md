# Participant guide
1. **Sign in** at `/login` with the email and password your organisers gave you. The dashboard shows your team, members, a server-synced countdown and announcements.
2. When Round 1 starts, open **Round 1**: three questions (DSA, OOP, DBMS) appear. Each has a problem, constraints, expected behaviour, example tests and the original inefficient code.
3. In the **workspace** pick a language, edit in the Monaco editor. Your work **autosaves** (status shown above the editor) and is restored after a refresh; each language has its own draft. "Restore starter code" resets the editor.
4. **Run** checks your code; **Submit final solution** records it permanently (you can submit again before the deadline). Results show one of: Accepted, Wrong answer, Compilation error, Runtime error, Time limit, Memory limit, System error. Hidden tests show only as pass counts.
   - ⚠ Real code execution is **not enabled** in this build: results are labelled **MOCK** or "not enabled" and say nothing about correctness.
5. Open the **Autopsy Report** tab: four sections (inefficiency, approach, complexity, trade-offs), each at least 30 characters. It autosaves; **Submit report** locks that version (you can create an amendment while the round is open). Status: Draft → Submitted → Evaluating → Evaluated → Reviewed.
6. Marks appear under **Results** only after the organisers publish them. Finalists see **Round 2** after it starts.
Deadlines come from the server clock; changing your computer's clock does nothing.
